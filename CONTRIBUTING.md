# Workflow Git
- `main` = stable (démo). `develop` = intégration. Une branche par tâche : `feat/<nom>-<sujet>`.
- Jamais de push direct sur `main` : Pull Request + 1 relecture.
- Commits courts : `feat:`, `fix:`, `docs:`, `data:`.
- Jamais de secrets, tokens, mots de passe, ni de données lourdes dans Git.
