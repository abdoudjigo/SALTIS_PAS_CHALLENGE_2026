# Business Model Canvas : Assaman & Suuf

Version texte de la slide 6 (annexe) de [`presentation-pitch.pptx`](presentation-pitch.pptx). **Proposition à valider par l'équipe** : aucun montant n'est encore fixé.

| Bloc | Contenu |
|---|---|
| **Segments clients** | Producteurs (bénéficiaires finaux) ; services de l'État ; ONG ; bailleurs et investisseurs ; associations de producteurs de semences (à confirmer) |
| **Proposition de valeur** | Producteur : savoir quoi semer et quand, selon la pluie attendue. État et ONG : répartir des intrants limités de façon traçable, entre rendement et équité. Bailleurs : repérer les terres à potentiel de contre-saison. Pour tous : des estimations transparentes, avec le statut de validation affiché |
| **Canaux** | Application web et mobile ; assistant vocal en wolof ; conseillers ANCAR ; démarchage des institutions |
| **Relations clients** | Libre-service pour les producteurs ; accompagnement et formation des organisations ; relais par les conseillers agricoles |
| **Sources de revenus** | Gratuit pour les producteurs ; abonnement annuel par organisation (État, ONG) ; études sur mesure pour les bailleurs ; subventions et prix au démarrage |
| **Ressources clés** | Données 1981-2025 sur 45 départements ; modèles d'IA et moteur AgroDistrib ; équipe AKAI (données, IA, web) |
| **Activités clés** | Collecte et transformation des données ; modèles (pluie, date de semis, répartition) ; carte interactive et assistant vocal ; validation avec les spécialistes |
| **Partenaires clés** | ISRA (validation des doses) ; ANCAR et services techniques ; DAPSA (rendements) ; données ouvertes (CHIRPS, NASA POWER, SoilGrids) ; bailleurs et PAS Challenge |
| **Structure de coûts** | Hébergement (un serveur et Snowflake) ; maintenance et évolution ; validation agronomique ; déploiement terrain et formation |

## Points à trancher

- Montants de l'abonnement annuel et des études sur mesure.
- Partenariats ISRA, ANCAR et DAPSA : cités comme cibles, aucun accord signé à ce jour (à vérifier par l'équipe).
- Associations de producteurs de semences : segment maintenu ou retiré (décision ouverte, voir [`etat-modelisation.md`](etat-modelisation.md), section 1).
