# Logo d'Assaman & Suuf

Le logo est un emblème rond, dessiné en vecteur à partir de `logo.png` (racine du dépôt, version illustrée d'origine).

![Logo](../app/public/logo.svg)

## Ce qu'il raconte
« Assaman & Suuf » veut dire « le ciel et la terre ».

| Élément | Sens |
|---|---|
| Ciel bleu et pluie | Le ciel qu'on lit : la pluie, la saison (modèles 1 et 2) |
| Soleil qui se lève sur l'horizon | La saison qui commence, le bon moment pour semer (modèle 4) |
| Rivière qui descend vers nous | L'eau qui arrive jusqu'au champ |
| Collines et sillons | La terre cultivée, la récolte (modèle 3) |
| Anneau vert foncé | Le cadre de l'institution, la couleur de la marque |

Par rapport à `logo.png` : moins de détails pour rester lisible à 16 px, pas de texte dans l'image (le texte anglais « Agroclimatic intelligence » est retiré, le nom s'écrit à côté), couleurs de la palette du projet.

## Fichiers
| Fichier | Usage |
|---|---|
| `app/public/logo.svg` | Logo à toutes les tailles (pages, documents) |
| `app/public/favicon.svg` | Le même dessin, icône de l'onglet ; utilisé par toutes les pages (en-tête, scène, pied de page) |
| `app/public/pwa-192x192.png`, `pwa-512x512.png` | Icônes de l'application installée (fond transparent) |
| `app/public/maskable-512x512.png` | Icône adaptative Android : emblème à 78 % sur fond vert, pour que le découpage ne le coupe pas |
| `app/public/apple-touch-icon.png` | Icône iPhone (180 px, fond vert plein) |

## Couleurs
| Couleur | Token | Valeur |
|---|---|---|
| Anneau | `vert-900` | `#12391f` |
| Ciel | `pluie-700` → `ciel-vif` → `ciel-lueur` | `#1b5a8e` → `#2f9cf0` → `#a9dcff` |
| Soleil | `soleil-500` | `#f2b544` |
| Collines | `vert-500`, `vert-700` | `#2f7d4f`, `#1f5f3a` |
| Pluie et rivière | `pluie-100` | `#dcecf8` |

## Règles d'usage
- Toujours le nom écrit à côté (« Assaman & Suuf »), jamais dans l'image.
- Ne pas déformer, ne pas recolorer, ne pas ajouter d'ombre.
- Taille minimale : 16 px.
- Fond clair ou fond vert foncé : l'anneau garde le logo lisible sur les deux.
